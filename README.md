> ### РЕАКЦИЯ АНТИВИРУСОВ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret необходим WinDivert — инструмент, перехватывающий и фильтрующий трафик.
> Его способны применять как легитимные, так и вредоносные программы, однако сам инструмент вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как объекты повышенного риска либо хакерские инструменты, после чего удаляет их или отправляет в карантин. Название такого детекта обязательно содержит `WinDivert` или выглядит как `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку с запретом в антивирусные исключения либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Касперском предусмотрен пункт «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если умеете безопасно настраивать исключения, рекомендуется выбрать этот вариант; если не уверены в своих действиях — отключите обнаружение PUA.

## ⚙️Порядок использования

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите «Использовать безопасный DNS» и укажите поставщика DNS, не выбирая вариант «Поставщик по умолчанию»
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную укажите URL. Например, подойдёт `https://dns.google/dns-query`, поскольку поставщик Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах ОС — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * Владельцам роутеров Keenetic нужно включить параметр «Транзит запросов». Если он выключен, при настройке и работе Secure DNS на компьютере возможны проблемы

2. Загрузите архив zip/rar со [страницы актуального релиза](https://github.com/HeightAlbatross/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте «Разблокировать». При использовании 7-Zip или PeaZip этот пункт выполнять не требуется

4. Извлеките архив в каталог, путь к которому не включает кириллицу и специальные символы

5. Откройте подходящий файл
    * Чтобы определить рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы настроить автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Этот способ позволяет вручную проверить, работает ли выбранная стратегия. Результат зависит от множества факторов. **Перебирайте стратегии ALT, FAKE и остальные, пока не найдёте подходящий для себя вариант**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные возможности:
  - <ins>**`Install Service`** — добавляет любую стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из списка служб
  - **`Check Status`** — показывает состояние обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — меняет режим обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения параметра перезапустите стратегию.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — изменяет режим обхода сервисов, перечисленных в `ipset-all.txt`.  
  Пригодится для тестирования ресурса, который работает без zapret, но недоступен вместе с ним  
  В скобках отображается активное состояние:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP-адреса в списке
    - `any` — фильтр применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включает или отключает автоматический поиск обновлений
  - **`Replace active fakes`** — меняет указанный активный фейк на другой файл из каталога `bin`
  - **`Update IPSet List`** — загружает в `ipset-all.txt` актуальный список из репозитория
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ищет доступные обновления
  - **`Run Diagnostics`** — проверяет распространённые причины неработоспособности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это может помочь, если приложение внезапно перестало работать
  - **`Run Tests`** — открывает инструмент проверки работоспособности стратегий:
    - `Standard tests` — тестирует сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` — проверяет DPI через разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неполадки

### Скрипт `general*` запускается, но ничего не происходит

- При ручном запуске стратегии отдельным bat-файлом, а не через service, должен открыться процесс winws.exe (обход), видимый на панели задач.  
Если он не появился, ознакомьтесь с [#522](https://github.com/HeightAlbatross/zapret-discord-youtube/issues/522)

### Не работает ни одна стратегия
- Откройте командную строку с правами администратора
- По очереди выполните в консоли следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Выполните перезагрузку компьютера

### Веб-версия Telegram не открывается
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если ваш hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте полностью текст из открытого блокнота
  - В появившемся каталоге откройте файл `hosts` через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленный похожий фрагмент
  - Сохраните файл и снова проверьте подключение. Если результата нет, удостоверьтесь, что изменения в `hosts` действительно сохранились.

#### Работоспособность не гарантируется. Если способ не помог, воспользуйтесь [Desktop-версией](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/HeightAlbatross/tg-ws-proxy) либо любым публичным прокси.

### Обход не запускается или больше не работает

> [!IMPORTANT]
> **Любая стратегия со временем может утратить работоспособность.**
> Некоторый период выбранная стратегия способна работать, но после обнаружения её эффективность может исчезнуть.
> Репозиторий содержит много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе представленной здесь, изменив её параметры.
> Описание параметров стратегий опубликовано [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь в отсутствии ошибок через `service.bat` -> `Run Diagnostics`

- Проверьте, присутствует ли адрес нужного ресурса в списке доменов или IP

- Переключитесь на другие стратегии, включая **`ALT`**, **`FAKE`** и остальные

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/HeightAlbatross/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить программу?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`, устраните найденные ошибки и в конце нажмите Y
- Удалите каталог с запретом
- Загрузите актуальную версию [со страницы релизов](https://github.com/HeightAlbatross/zapret-discord-youtube/releases), выбрав `zapret-discord-youtube-...`
- Откройте свойства архива через контекстное меню. Если справа внизу доступен пункт «Разблокировать», отметьте его и нажмите «Применить» -> «ОК»
- Распакуйте файлы в новый каталог в корне диска, исключив из пути пробелы и специальные символы
- Поочерёдно запускайте разные скрипты `general` — стратегии. Проверяйте доступность интернет-ресурсов; если они не открываются, закройте программу через значок замка на панели задач и перейдите к следующей стратегии
- Найденную рабочую стратегию можно добавить в автозапуск: `service.bat` -> `Install Service` -> выберите нужный вариант

### При включённом запрете перестала работать игра или программа

- Проверьте настройки service.bat: `Game Filter` должен иметь статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может неожиданно повлиять на доступность других ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert не исчезает

1. Определите имя службы, выполнив в командной строке Windows (Win+R, `cmd`) команду:

```cmd
driverquery | find "Divert"
```

2. Завершите работу службы и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте правильность настройки [Secure DNS](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- Дополнительно см. [#251](https://github.com/HeightAlbatross/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить именно её.
- Откройте `service.bat` -> `Run Diagnostics`, затем очистите кэш Discord.
- Снова проверьте Discord: изменилась ли ситуация после очистки кэша?
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если браузерная версия также недоступна, повторно переберите все стратегии. Иногда одна стратегия открывает YouTube, но не Discord.
- Дополнительные сведения: [#252](https://github.com/HeightAlbatross/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь приложением [tg-ws-proxy](https://github.com/HeightAlbatross/tg-ws-proxy)
- Другой вариант — бесплатные MTProto-прокси из интернета

### Игры не работают

Игр существует очень много, поэтому проверить и исправить каждую невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, затем активируйте `Game Filter`
- если результата нет, дополнительно включите параметр `ipset any`

Учтите, что режим `ipset any` создаёт проблемы с доступом ко многим сайтам, поэтому не оставляйте его включённым постоянно. Вместо этого определите все используемые игрой IP-адреса и внесите их в `ipset-all.txt`

Если перечисленное не помогло, создайте тему в разделе [Discussions](https://github.com/HeightAlbatross/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

## 🗒️Как добавить адреса других ресурсов

Расширить перечень адресов для обхода можно с помощью файлов:
- **`list-general-user.txt`** — домены; их поддомены учитываются автоматически
- **`list-exclude-user.txt`** — исключения для доменов, например когда IP сети находится в `ipset-all.txt`, но отдельный домен из неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключения для IP-адресов и подсетей
  - Файлы **`*-user.txt`** будут созданы автоматически после первого запуска `zapret` или `service.bat`
